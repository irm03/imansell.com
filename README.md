# imansell.com

## Editing the cards
Everything you'd normally change is in **cards.js**.

1. Open `cards.js` on github.com and click the pencil icon.
2. Add, remove, reorder or edit a `{ title, link, description }` block.
3. Click **Commit changes**. The site updates by itself within a minute or two.

The List and the Sisyphus hill both read from this one file.

## Files
- `index.html`: the page itself (design and Sisyphus). You shouldn't need to touch it.
- `cards.js`: the cards.
- `CNAME`: tells GitHub Pages the site lives at imansell.com. Leave it alone.
